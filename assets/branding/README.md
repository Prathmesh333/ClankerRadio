# Clanker Radio mascot

`clanker-radio.png` is the approved Bubble Bot image, selected by the user. Preserve its transparent background and original proportions. Generated with the built-in image generator from the direction: a cute, rounded robot-radio with kind crescent eyes, a gentle smile, speaker grilles, warm amber indicators, and a short round-tipped antenna.

Run `npm run branding:prepare` to create the public player PNG and Windows/browser ICO assets. This only resizes and converts the approved image; it does not regenerate the artwork. The ICO contains 16, 24, 32, 48, 64, 128, and 256 pixel frames.
