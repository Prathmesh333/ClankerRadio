## Original specification

The [original specification pack](../clanker_radio_docs/README.md) is preserved in its supplied directory, including schemas and configuration examples. It describes a broader production pipeline, including calm music, 50 proposed scenes, offline export, and publishing. Those are historical requirements or future plans; the current guides describe what is implemented.

The [classic visualizer research](../clanker_radio_docs/11_CLASSIC_VISUALIZERS.md) records the Butterchurn and MilkDrop implementation references.
